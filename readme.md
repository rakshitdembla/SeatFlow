# SeatFlow 🎟️

> A production-ready Event Ticket Booking Backend built with Spring Boot.

🚧 **Currently under development.**

This project is being built to explore modern backend development using Spring Boot and production-ready technologies.

### Planned Features

- JWT Authentication
- Event Management
- Seat Booking
- Razorpay Payments
- Booking History
- Redis Caching
- Kafka Event Processing
- Email Notifications

### Tech Stack

- Java
- Spring Boot
- Spring Security
- PostgreSQL
- Redis
- Apache Kafka
- Razorpay
- Docker
